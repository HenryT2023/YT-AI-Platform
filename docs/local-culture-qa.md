# 严田有出处文化问答

入口为原严田 OS 内的 `/studio/#qa`；第一层运营空间的辅助入口也可进入。
工作室、原知识接口、NPC 和只读检索继续使用 Core 创建的唯一 CultureService
和既有文化 SQLite。没有建立第二份可编辑文化库。

## 资料与回答

本机文化原稿按来源文件版本、文件 SHA256 和原文段落定位入库。首批限定为
村落历史、景点、资源、建筑等文化资料；人员摸底、联系方式、客户、资金和
账号记录不作为文化内容导入。原文件保持不变，选段保存在本地文化库。

来源可被读取、选段与原件一致、文化事实已经独立核实，是不同的状态。
本次原稿以“资料记载、待核实”进入问答，不因文件存在、旧种子 verified
标记或此次整理授权而成为已审定事实。地区文化背景与严田具体对象分开。
历史记载也不能证明今天的开放、师资、房态或交付条件。

问答逐项显示来源、版本、段落、原文摘录与待核状态。不同说法并列呈现，
不能把迁入时间、建村时间或相关年代混为同一个结论。没有匹配材料时提示
证据不足及可关联缺口。当前是本地检索与摘录，没有接入生成式模型或训练权重。

来源详情只能按已登记来源/段落 ID 查询库内选段，不接受任意硬盘路径，
不在页面显示私人绝对路径。来源内容作为资料展示，不能作为系统指令执行。

## 入库与版本

使用工作室的固定导入契约和本地导入工具。先验证包结构、原件哈希、来源
定位、选段、知识与问题引用，再在文化 SQLite 的同一事务中保存来源、
知识版本、段落、缺口/争议和导入回执。相同包重放不重复创建知识；资料或
选段变化追加版本，不覆盖原出处或继承旧的事实/工艺批准。

实际导入前用 SQLite backup 备份原文化库；只在独立测试库验证导入失败、
重放和版本变化。原房态/订单/收款、木刻稿样和专业审阅不因资料导入而变更。
此次允许的用途为本地整理和检索；公开传播、商业改编及训练用途分别保留待确认。

## 本地使用与验证

先按 `local-os-integration.md` 启动原 OS，再进入文化问答。检查资料记载题、
争议题、缺失题和地域边界题，逐一打开出处核对原文。桌面与手机检查提问、
结果、来源展开、缺口和失败状态。示例答案取自实际导入资料，不能预填虚构史实。

文档导入与问答测试不调用外部模型、云存储、发布平台或设备。验收记录应
区分软件功能、原件抽取对照、文化专业审核和模型训练；机器接口继续预留。
